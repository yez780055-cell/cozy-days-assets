# 小饱日常 Cozy Days · Android 素材交接包

## 内容
- `sources/`: 10 张原始参考/生成素材，一律只读；均非已拆分的正式独立文件。
- `docs/ASSET_SPLIT_MANIFEST.csv`: 详细的素材拆分目标、来源、定位、产出格式、注意事项。
- `docs/SOURCE_AUDIT.json`: 实际读取到的每张图片尺寸、通道信息与背景注意事项。
- `docs/CODEX_PROMPT.md`: 复制给 Codex 的完整任务说明。

## 重要事实
1. 文件名带 transparent 不意味着真实透明！部分 PNG 的棋盘格是图像像素。不要仅凭扩展名或 alpha 通道存在判断背景透明。
2. 这套素材大多是依据原UI图重新生成的风格参考，并非逐像素无损抠图。不要声称完全复刻或未经更改。
3. 原图为合成概念稿，素材彼此可能存在姿态、比例或细节差异，应以视觉对照和实用性优先。
4. 不可把位图 PNG 直接改名为 SVG；复杂插画维持带 alpha 的 PNG/WebP，简单符号才用真正的矢量路径。
5. 像素级自动裁切结果要做 QA；若去除棋盘格可能损坏粉白浅色区域，要先保留可编辑中间成果供人工复核。

## 交付验收
- 每个 PNG 真实 alpha；以深/浅双色底预览没有棋盘格、脏边、错误透明洞；不含相邻素材。
- SVG 能在浏览器正确渲染，viewBox 和路径有效，缩放清晰。
- 规范命名和目录，生成 contact sheet（接触图/缩略图总览）及每项质量检查清单。
- Android 页面使用的具体 dp 尺寸按用途配置，不把 PNG 像素尺寸直接理解为 dp。
